# Nova – Landing Page

A responsive landing page for **Nova**, built as a design-to-code project.

## Sections

- Navigation bar with logo, links and "Get Started" button
- Hero with headline, subtext, call-to-action and laptop image
- "Why Choose Nova?" with three feature cards: Super Fast, Secure & Reliable, Built for Teams
- Call-to-action banner with "Sign Up Free" button
- Footer with navigation links and social icons
